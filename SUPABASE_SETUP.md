# 🚀 Настройка Supabase для SkladPro

## 📋 Пошаговая инструкция

### Шаг 1: Создание проекта Supabase

1. Перейдите на [supabase.com](https://supabase.com)
2. Войдите через GitHub или создайте аккаунт
3. Нажмите **"New Project"**
4. Выберите организацию или создайте новую
5. Введите имя проекта: `skladpro`
6. Выберите регион (ближайший к вам)
7. Создайте и сохраните пароль от базы данных
8. Нажмите **"Create new project"**

### Шаг 2: Получение API ключей

1. Дождитесь создания проекта (2-3 минуты)
2. Перейдите в **Settings → API**
3. Скопируйте:
   - **Project URL** (например: `https://abc123.supabase.co`)
   - **anon public** ключ (начинается с `eyJ...`)

### Шаг 3: Получение строки подключения к БД

1. В том же разделе **Settings → API**
2. Найдите **Project URL** и **Connection string**
3. Скопируйте строку подключения вида:
   ```
   postgresql://postgres:your-password@db.abc123.supabase.co:5432/postgres
   ```

### Шаг 4: Настройка базы данных

1. Перейдите в **SQL Editor**
2. Откройте файл `supabase_schema_fixed.sql`
3. Скопируйте весь SQL код
4. Вставьте в SQL Editor и нажмите **"Run"**

### Шаг 5: Настройка .env файла

Откройте файл `backend/.env` и замените:

```bash
# Замените на ваши данные:
SUPABASE_URL=https://abc123.supabase.co
SUPABASE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.ваш-ключ
SUPABASE_DB_URL=postgresql://postgres:пароль@db.abc123.supabase.co:5432/postgres
DATABASE_URL=postgresql://postgres:пароль@db.abc123.supabase.co:5432/postgres
```

### Шаг 6: Запуск проекта

1. Установите зависимости бэкенда:
   ```bash
   cd backend
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

2. Запустите бэкенд:
   ```bash
   uvicorn main:app --reload
   ```

3. В другом терминале запустите фронтенд:
   ```bash
   cd frontend
   npm run dev
   ```

## 🔍 Проверка работы

1. Откройте [http://localhost:5173](http://localhost:5173)
2. API документация: [http://localhost:8000/docs](http://localhost:8000/docs)
3. Проверьте, что товары с местоположением отображаются корректно

## 📦 Примеры товаров с местоположением

После выполнения SQL схемы будут созданы тестовые товары:

| Товар | Местоположение | Штрих-код |
|--------|---------------|------------|
| Масло моторное 5W-30 | A A1:1 | 1234567890123 |
| Фильтр масляный | A A1:2 | 2345678901234 |
| Тормозные колодки | B B1:1 | 3456789012345 |
| Свечи зажигания | B B1:2 | 4567890123456 |
| Антифриз | C C1:1 | 5678901234567 |

## 🛠️ Структура местоположений

```
Ряд A: [A1:1] [A1:2] [A2:1] [A2:2]
Ряд B: [B1:1] [B1:2] [B2:1] [B2:2]  
Ряд C: [C1:1] [C1:2]
```

Формат: `Зона РядСтеллаж:Позиция`

## 🚨 Возможные проблемы

### Ошибка: "column is_stale specified more than once"
**Решение:** Используйте файл `supabase_schema_fixed.sql`

### Ошибка: "connection refused"
**Решение:** Проверьте правильность DATABASE_URL в .env

### Ошибка: "auth.role() does not exist"
**Решение:** Включите RLS после создания таблиц

## 📞 Поддержка

Если возникли проблемы:
1. Проверьте все шаги инструкции
2. Убедитесь, что SQL схема выполнена полностью
3. Проверьте правильность ключей в .env файле
