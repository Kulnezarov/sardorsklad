# SkladPro — бриф для клиента (склад без витрины)

> Документ для созвона и уточнения требований. Можно распечатать или отправить клиенту перед встречей.

---

## 1. Что это за проект (коротко)

**SkladPro** — система учёта склада автозапчастей: приёмка, хранение, продажа, резерв у поставщика, ревизия, история, этикетки.

| Часть | Для кого |
|-------|----------|
| **Сайт (админка)** | офис, менеджер, старший кладовщик |
| **Мобильное приложение** | работа на полу склада, касса, приёмка |
| **Сервер** | общая база для сайта и приложения |

**Витрина (публичный каталог для покупателей)** — опциональна. Режим «только склад»: учёт и продажи в зале работают без выкладки товаров на сайт.

---

## 2. Что входит в «склад без витрины»

- Каталог товаров: карточка, категории, шаблоны полей, фото, штрихкод, ¥→₸
- **Накладная (приёмка)** — новые позиции до поступления на склад
- **Резерв** — заказы поставщику, статусы
- **Продажи** — касса/POS, сканирование
- **В долг** — клиенты, задолженность, погашение
- **Ревизия** — сверка факта с учётом
- **История** — журнал операций
- **Этикетки** — печать штрихкода (в т.ч. Xprinter 6×4 см)
- **Настройки** — категории, курс ¥, тариф доставки, совместимость авто
- **Excel** — импорт/экспорт каталога

## 3. Плюсы и минусы (честно)

### Плюсы

| Область | Что даёт |
|---------|----------|
| Учёт | Один источник правды вместо Excel + мессенджеры |
| Скорость | Скан штрихкода, автоподстановка карточки и цен |
| Автозапчасти | Совместимость, закуп ¥, накладная, этикетки |
| Пол | Мобилка: приёмка, продажа, скан |
| Контроль | История, ревизия, долги, дашборд |
| Масштаб каталога | Подгрузка порциями, поиск, массовое редактирование |

### Минусы / ограничения (сейчас)

| Область | Ограничение | Что спросить у клиента |
|---------|-------------|------------------------|
| WMS | Место — текстовое поле, не карта ячеек | Нужны зоны/стеллажи/ячейки? |
| Филиалы | Один склад в логике | Несколько точек? |
| Офлайн | В основном накладная | Плохой интернет на полу? |
| Роли | admin / manager | Нужны «только касса», «только приёмка»? |
| Интеграции | API есть, 1С — отдельно | 1С, Kaspi, бухгалтерия? |
| UI | Переключатель «витрина» в каталоге | Скрыть под «только склад»? |

## 7. Pitch для клиента (30 секунд)
